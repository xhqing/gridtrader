# quant — 量化策略开发 skill

> **Markowitz 的核心 skill**：设计可回测的交易策略代码，用历史数据回测标定其可信度，产出经回测验证的量化策略与结论。
> 本文件是执行规范与铁律；输入输出契约见 `schema.md`，数据源见 `data-sources.md`，目录约定见 `README.md`。

## 触发规则

当用户要求**开发 / 设计 / 改写可回测的量化策略、跑历史回测、标定策略可信度、讨论策略的胜率 / 赔率 / avg_R**时，激活本 skill。

本 skill **不盯盘、不下单、不发实时交易信号**，也不做策略结论的最终实盘决策。

## 定位：独立、可回测的量化策略研究

本 skill 是独立的量化研究：Markowitz 写一套确定性的量化策略代码 → 用历史数据回测它（合法性：确定性代码无前视偏差、可复现）→ 回测结果标定该策略信号的可信度。结论只认同口径回测，不依赖任何主观判断背书。

类比：一套技术指标系统（量化策略）——它本身可以严格回测，回测告诉你它历史上多靠谱；实盘是否采信、仓位多大，由使用者自己决定。

**关键边界**：

1. **可回测因子 vs 不可回测因子干净分开（核心）**：
   - **可回测**（历史数据有）：K 线 OHLCV、成交量、换手、均线、突破回踩 → 纳入量化策略模块，能回测标定。
   - **不可回测**（仅实时有、历史无 / 浅）：资金流 `capital`、Level2 盘口、经纪队列、新闻、宏观基调 → **不进**可回测模块。
   - 硬约束：**一个因子要被回测标定，其历史数据必须可得**——这卡死了量化模块的边界，但也保证回测可信度是实打实标定过的。
2. **信号对齐（最关键，做歪就废）**：回测的开 / 平仓定义必须和实盘执行的信号定义**严格一致**（顺势标准、合格入场点、止损反推仓位、时点约束）。若回测的是「简化版信号」，回测出的胜率迁移到实盘真实执行会失真——回测对象与实战对象要同质化，可信度才有参考价值。
3. **双用途、同一套代码**：回测与盘中实时产信号用同一套代码同一套逻辑，保证回测可信度认得上实时信号。
4. **信号是辅助证据，非决策主体**：量化信号不当机械指令（市场状态切换会让历史胜率失效），而是带置信度分级的参考——历史可信 → 增强采信；与主观判断反向 → 警示重审是否漏看；无信号 → 弃权不干扰。

## 三条铁律（最高优先级，用户立）

1. **时间必带市场时区**：港股用北京 / 港时（`+08:00`），美股用美东（`EDT -04:00` / `EST -05:00`）。ISO 8601 带偏移。禁止无时区时间戳。
2. **输出全量化**：每个字段要么是**数值**（价格 / 量 / 比率 / 百分比），要么是**有限枚举**（离散值，数值编码）。**禁止定性文字**（如「5 日均线上行」「动能减弱」）。这是量化区别于主观交易的本质。
3. **schema 与回测协同设计**：只有输入（K 线 OHLCV）和输出（本 schema）都可量化，回测才能**精准复现**（同数据 + 同参数 → 同结果）。

> 判定依据不许写文字，必须转成一组数值 `features`（如均线值、斜率、量比、ATR）。定性结论（方向 / 状态）只作为这些数值的离散枚举结果输出。

完整契约与回测设计见 `schema.md`。

## 核心设计原则

1. **策略只分类，置信度由回测赋予**：策略模块输出信号方向 + **类别签名**（不自己打分）；置信度 = 该类别在回测里的历史胜率 / EV。策略模块自评的「分」和回测脱节、不可信，故不用。
2. **双用途、同一套代码**：回测和盘中实时调同一份策略逻辑，保证回测出的可信度认得上实时信号。
3. **只用可回测因子**：日 K（OHLCV）+ 分钟 K（OHLCV）。富途 OpenD 有约 5.5 年分钟 K（2021-01 起）——分钟级日内策略可回测。资金流 / 盘口 / 换手率无历史，仍不进策略。
4. **策略是纯函数**：`evaluate(bars, params) -> dict | None`，无随机、无全局状态、无副作用、无未来函数 → 同 `bars` + 同 `params` 永远同输出。
5. **优化目标 = `avg_R`**（平均风险倍数盈亏 = 期望值 expectancy 的 R 标准化），不是胜率、不是总收益率。

## 工作流（加 / 改一个策略）

1. 在 `strategies/` 加一个 `.py`，实现统一接口 `evaluate(bars, params) -> dict | None`：输入截至当前根的历史 K 线（含时区）→ 输出战略层 / 战术层 schema dict，或 `None`（无信号）。**输出不含置信度**，置信度由回测赋予。
2. 在 `backtest.py` 注册该策略 → 跑回测 → 生成该策略各类别的历史胜率 / 赔率 / avg_R / 样本数查表。
3. 盘中实时调用：策略出信号 + 签名 → 查回测表得该类历史胜率（= 自评置信度）→ 使用者自行综合进最终决策。
4. 配套：样本量太少的类别（如 < 20 次）置信度打折（`low_sample: true`）；查无的新类别 → `confidence=null`，弃权、不干扰。

## 数据约束（实测）

- **富途 OpenD 分钟 K**：约 5.5 年（2021-01-21 起），1m / 5m / 15m 均有；单次 `max_count` 上限 10 万根，分页拉全量。**分钟级日内策略回测的主力源。** 符号 `市场.代码` 前缀（`HK.02800`）；离线时 `open ~/FutuOpenD/FutuOpenD.app` 启动。
- **长桥日 K**：单次上限 1000 根，分页拼接（每页约 4 年）可拉十几年；港股美股均支持。符号 `代码.市场` 后缀（`02800.HK` / `SPY.US`）。
- **资金流 / 盘口 / 换手率**：无历史，**不进策略**。

完整数据源调研（含付费第三方渠道、踩坑备忘）见 `data-sources.md`。

## 当前阶段

MVP 已就位：schema、回测设计、数据源调研、数据层 `data.py`、**回测驱动器 `backtest.py`**（读缓存 → 逐根喂策略 → 内置出场 → 算 R → 类别统计 → 泛化测试）、**第一个策略 `strategies/trend_breakout.py`**（5m 动量突破）。

已修回测口径关键 bug（教训，写策略/改框架必看）：
1. **未来函数**：信号在 t 根收盘后产生 → 必须 t+1 根开盘价成交；严禁用信号根自己的开盘价成交（曾是最大美化源，毛 avg_R 从 0.57 跌到 0.08）。
2. **出场价保守端**：同一根内价格可穿 stop/take，出场价 = min/max(close, 触发价)（止损取低端、止盈取高端），不取「恰好触发价」也不取「裸 close」。
3. **时段约束**：进场根必须在开盘后、尾盘前（港股 09:30–15:30 / 美股 09:30–15:30），收盘 K（12:00/16:00）不能进场。
4. **risk 下限**：`|entry-stop| < 0.3% 价格`的交易无统计意义（低波动品种如盈富 5m 止损过近 → R 爆炸 ±40），跳过不进统计。

第一个策略回测结论：盈富 5m 净 avg_R 0.027（微正）、SPY 净 avg_R -0.015（负）——**扣成本后基本无 edge**，被泛化测试进一步验证（详见输出）。

### 系统性证伪结论（2026-08-03，重要——勿重蹈覆辙）

对**两个相反的入场逻辑**（`trend_breakout` 动量突破追涨 / `mean_reversion` RSI 均值回归抄底）在**全股票池（港股 3 + 美股 2）× 5m/15m × 合理参数网格**（含 train/test 防过拟合）回测，**全部 g<0，无任何 train+test 双正的稳健组合**。trend_breakout 在 QQQ 15m 上有 5 组 test g>0，但 train g 全负——是时间过拟合的假阳性，g 框架 + train/test 正确拦截。

**根因（毛 EV 诊断）**：两个策略的**毛 EV 全部 ≈ 0**（−0.09 ~ +0.04 R），即指标本身在 5m/15m 上几乎没有预测力（符合弱式有效市场——公开技术指标已被充分定价）。成本只是把「毛 EV≈0」压成「净 EV 明确为负」：港股印花税每笔侵蚀 0.5-0.8R（致命），美股侵蚀 0.1-0.14R。**所以失败根因是「指标无预测力」而非「差一点被成本拖累」**——调参救不了无预测力的指标。

> **边界（勿过度泛化）**：本结论仅适用于「当前免费数据（5 个高流动性标的）+ 5m/15m 日内 + 简单 K 线技术指标（动量/RSI）+ 真实成本」。**不**外推到：日 K 波段（趋势预测力更强、成本占比骤降）、多因子组合（弱指标叠加可能产生 edge）、跨标的相对策略（配对/套利）。在这些方向突破前，Markowitz 暂无可交付的策略。

下一步候选方向（按可行性）：① 多因子组合（在日内框架内争取把毛 EV 从 ≈0 做到 > 成本）；② 日 K 波段（偏离日内目标但 edge 更可能存在）；③ 跨标的相对策略；④ 重新定位 Markowitz 为「负面证据提供者」（证伪常见思路、帮实盘避坑）。方向待定，不盲目试第 N 个单指标策略。

### 多因子突破：盈富 15m 顺势深回踩（2026-08-04，第一个真实 edge）

选方向 A（多因子）。新增 `strategies/multi_factor.py`（**趋势过滤 MA + RSI 回踩 + 放量确认**三因子 AND，对应 schema 的 `entry_condition: pullback_hold`）+ `add_indicators` 的 MA/slope。设计依据：单动量（追高买顶）、单均值回归（逆势被碾压）都毛 EV≈0；顺势（方向对）+ 等深回踩企稳（不追高）+ 放量确认（反弹有效）综合三者优点。

**在盈富 15m 找到统计显著的真实 edge**（推荐配置 `ma_period=15/oversold=30/vol_threshold=1.0/stop=2/take=3/hold=48`，CLI 用 `--params` 传入）：

| 证据 | 结果（符合实盘止损口径，见 4.5） |
|---|---|
| 全样本 | n=43，胜率 62.8%，毛 EV **+0.867R**，净 EV +0.185R，**g=+0.333%/笔**，f*=+10.2% |
| train/test | train g +0.320%、test g +0.375%（双正，**test 高于 train**，非过拟合） |
| 按年分解 | **2020-2026 共 7 年全部毛 EV 为正**（+0.23 ~ +1.59），p≈0.5⁷≈0.008（统计显著） |
| 关键规律 | edge 来自「深度（RSI<30）+ 顺势」的稀缺组合；浅回踩（os≥35）样本多但毛 EV 跌到 +0.17、g 转负——质量 > 数量 |

> **g 数字修正说明**：初版（2026-08-04）用 `min/max(close, stop)` 出场口径得 g=+0.727%，但该口径在止盈端高估盈利（冲高取更高的 close）。当日修正为符合实盘止损止盈单的口径（盘中触及即在触发价成交、跳空才用 open）后，g 回归 +0.333%。edge 本身（7/7 年正、train+test 双正）不变，只是去除了止盈端美化。

### 日内禁跨段约束摧毁 edge（2026-08-04，重要负面发现）

随后定稿**日内固定止盈止损模式**：① 固定止损/止盈、成交价恒定 = stop/take（市价单触及即成交，禁跨段无跳空）；② **日内禁跨段**——持仓到午休前/收盘前强制平仓（用收盘价），不过午休不过夜；③ 去掉 trailing/反向信号（实测纯 trailing 在此策略 g 全负）。

**结果：multi_factor 在盈富 15m 上 edge 消失**。A 方案（禁跨段）下所有 stop/take 参数组合 g 全负（−0.26% ~ −2.0%），最佳 stop=2/take=3 也只 g=−0.260%（vs 允许跨段时的 +0.333%）。

**根因**（段末强平笔 R 均值 +0.331，是浮盈不是浮亏）：禁跨段让 25/43（58%）交易在段末被强平时仍浮盈 +0.33R（没等到 +1.5R 的 take 兑现）——**盈利兑现不充分**，叠加港股重成本（18bps 印花税）把微薄盈利压成净负。允许跨段时这些交易能继续持到 +1.5R，覆盖成本后有 edge。

**诚实结论**：multi_factor 盈富 15m 的 edge（+0.333%）**依赖跨段持仓**（让盈利充分兑现），本质是「短周期波段」而非「纯日内」。在用户的纯日内约束（禁跨段 + 港股真实成本）下，该策略无 edge，**不交付使用**。这印证了「系统性证伪结论」的边界——简单技术指标在纯日内 + 真实成本下难有稳健 edge。下一步：① 试美股（成本低，+0.33R 段末强平可能覆盖成本）；② 接受日内无 edge，转方向 B（日 K 波段，本就跨夜）；③ 寻找真正段内能兑现的趋势型策略/标的。

### 方向 B 日 K 波段探索：同样无稳健 edge（2026-08-04）

转日 K 波段。框架适配 `_allow_entry` 对 DAY 放行（日 K 次日开盘成交、无盘中时段）。探索：
- **multi_factor 日 K 不成立**：上升趋势中 RSI<30 极罕见，三条件 AND 全样本 = 0 次。日 K 趋势持续、深回踩少，"顺势回踩"逻辑不适用。
- **trend_breakout 日 K 固定止盈**：g=+0.041%（微弱，n=20）。
- **trailing 让利润奔跑**：g 从 +0.041% 跳到 +0.826%（20 倍），最大 R +1.5→+5.7——印证日 K 趋势延续性强、**trailing 显著优于固定止盈（与日内相反）**。

**但稳健性验证全部失败**：① 按年仅 4/6 年正（2023 −1.00、2026 −0.90 负）；② **train −0.058% vs test +3.775%（时间过拟合）**；③ 跨标的混乱（腾讯 −0.22%、QQQ −0.41%、SPY +2.25% 但 n=5 不可信）。根因：**trailing 放大少数大胜（+6R），样本仅 13 笔时 g 由一两笔大胜决定**，不稳健——换个时间段就消失（train 期已证明无 edge）。

**终极诚实结论（2026-08-04）**：在当前数据（5 个高流动性标的）+ 简单技术指标（动量/RSI/突破/趋势跟随）下，**无论日内还是日 K，都找不到稳健 edge**。这彻底印证「系统性证伪结论」——**简单技术指标在现代高效市场（尤其 ETF / 大盘股）已被充分定价，难有超额预测力**。不是策略没调好，是市场效率的铁律。g 框架 + train/test + 按年 + 跨标的的多重验证，正确地把所有「看似有效实则过拟合 / 小样本偶然」的假阳性都拦下了。

### 扩样本突破：趋势跟随稳健 edge（2026-08-04，里程碑）

单标的 edge 不稳的根因是**样本不足**（盈富 6.4 年/13 笔）。扩样本：`STOCK_POOL` 5→23 标的（港股大盘股 + 美股科技/ETF），日 K 历史 6.4 年→~20 年（`_fetch_range` 日 K 起点改 2000，富途可到 2006；翻 3 倍）。

**trend_breakout 日 K + trailing（让利润奔跑）在 23 标的 × 20 年上展现稳健 edge**——三重验证通过：

| 证据 | 结果 |
|---|---|
| 跨标的 | 17/23 标的 g 正（跳空建模后；趋势型强：TSLA/NVDA/AAPL/港交所 +1.1%~1.5%；防御/区间标的负：长和/海油/友邦/阿里，趋势跟随在震荡股失效，合理） |
| 按年 | 21 年里 **16 年池化 g 正**（负年份仅 2008 金融危机、2011 欧债等震荡市，趋势跟随已知弱点） |
| 参数稳健 | trail_atr 2-5 池化 g 全正（+0.23%~+0.82%）、正年数 14-17/21——**参数高原非孤峰**，非过拟合 |
| 整体 | 池化 1305 笔、g=+0.406%/笔（跳空建模后，见下）、EV净=+0.235R（trail=3） |

**这是 Markowitz 第一个可交付的稳健策略**：趋势跟随（`trend_breakout` + trailing 日 K）。诚实标注：是"固定参数三重验证"（跨标的 + 按年 + 参数稳健），非严格 train→test 调参 walk-forward；但参数稳健性（trail 2-5 都正）大幅降低过拟合风险，三重证据足以支持"稳健 edge"判断。

> 关键教训：**单标的/短历史的 edge 几乎都是小样本偶然**（之前盈富 +0.826% 的 train负test正 就是）；只有**多标的池化 + 长历史（20 年+）**才能把偶然平均掉、让真实 edge 显现。趋势跟随本就需大样本长周期——这正是扩样本的价值，不是凑数。

**跳空建模订正（2026-08-04）**：日 K 波段持仓隔夜，开盘跳空是真实风险（止损单市价、跳空开盘成交更差）。此前 `_exit_check` 恒定 stop（R 恒 −1）**美化了跳空**，现改为「跳空 open / 盘中 stop」口径后，池化 g 从 +0.501%（美化）订正到 **+0.406%（真实）**：77/1305 笔（5.9%）跳空穿透、最差 −7.84R。edge 仍在（g 正），跳空是代价但不致命（靠仓位管理）。

**实盘跳空处理**（隔夜持仓不可消除的风险）：① **仓位 f 控制（核心）**——最差 −7.84R 决定 f 上限，f=2% 单笔 −15.7% 致命，实盘用分数凯利 f≈1-1.7%（f*=6.9% 的 1/4，单笔最惨 −13% 可承受），绝不用 g 报告的 2%；② **多标的分散**——23 标的池化稀释单标的跳空（不同标的不在同一天跳空）；③ 期权对冲（买 put，成本高，波段策略少用）；④ 财报/宏观数据等可预测事件前减仓。认知：隔夜 = 用跳空风险换趋势机会，g 正说明长期 edge > 跳空代价，但单笔跳空致命性要求仓位必须小。

下一步：① 固化该策略（生成 23 标的池化 confidence 表交付使用）；② 可选严格 walk-forward（train 调参→test 验证）作终极加固；③ 剔除负 g 的防御/区间标的（长和/海油/友邦等），只对趋势型标的运行，提升池化 edge。
